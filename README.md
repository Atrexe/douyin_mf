# 全能视频解析工具

这是一个基于Python和PyQt5开发的全能视频解析工具，可以解析多个平台的视频，获取无水印的视频链接和下载地址。

## 功能特点

- 支持解析多平台视频（抖音、快手等）
- 支持视频和图集解析（线路1）
- 提供无水印视频直接播放功能
- 可以复制视频链接
- 支持直接下载视频到本地
- 解决了下载视频时的403错误问题
- 美观的用户界面，操作简单直观

## 安装和使用

### 环境要求

- Python 3.6 或更高版本
- 依赖包：requests, PyQt5, python-dotenv

### 安装步骤

#### 方法一：直接运行EXE文件（推荐）

1. [从Release页面下载最新的EXE文件](https://github.com/Atrexe/douyin_mf/releases/tag/v1.0.0)
2. 双击运行，无需安装任何环境

#### 方法二：从源码运行

1. 克隆或下载本仓库
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```bash
   python main.py
   ```

### 使用方法

1. 将视频链接粘贴到输入框中
2. 选择解析API线路（线路1支持视频和图集，线路2仅支持视频）
3. 根据需要选择是否直接播放
4. 点击"解析视频"按钮
5. 解析成功后，可以：
   - 查看视频信息
   - 复制视频链接
   - 直接在浏览器中打开视频
   - 下载视频到本地

## 系统兼容性

- 支持Windows 7/8/10/11系统
- 32位架构，兼容大多数Windows系统
